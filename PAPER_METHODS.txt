Image analysis and gradient quantification

Time-lapse GFP and Cy5 images of fluorophore-conjugated dextran were analyzed using a custom Python pipeline. The primary time-course analysis was performed at Z=11. A constant background of 100 intensity units was subtracted from each image, and negative values were set to zero.

Spatial illumination was corrected independently for each channel from overlaps between neighboring fields. Stage coordinates identified corresponding physical locations. After excluding dark and saturated pixels, median overlap intensity ratios were used to robustly fit a quadratic camera-X illumination profile. One profile per channel was estimated from all timepoints and applied before profile extraction. No independent flat-field image was used.

Fluorescence was averaged along Y to obtain one-dimensional gradients. Profiles were mapped onto a common physical X axis and combined in overlaps using complementary cosine weights, producing a continuous profile without double-counting. GFP and Cy5 profiles were normalized separately using one channel-specific maximum across the complete time course.

Each normalized profile was fitted to y(x) = L + (R − L)/2 × [1 + tanh((x − x₀)/w)], where L and R are the plateaus, x₀ is the midpoint, and w is the transition width. Robust bounded nonlinear least squares was used. Midpoint slope was m = (R − L)/(2w); signed slopes described direction and absolute slopes described steepness. Selected timepoints were also analyzed across Z with smoothed, overlap-derived per-Z corrections.

Quantification used TIFF data; PNG files were only for visualization. Code and configuration files are available at https://github.com/shellyefraim41/GradientanalysisExp106.
